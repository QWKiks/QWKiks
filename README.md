### <img src="https://api.iconify.design/octicon:rocket-24.svg?color=%233ecf8e" width="24" align="center" style="vertical-align: middle; margin-right: 8px;" /> Featured Projects

* **[OpenWeb](https://github.com/QWKiks/openweb)** — *Open-source browser automation for AI agents*
  * **Concept:** A specialized tool enabling AI agents (such as Claude Code, Cursor, Windsurf, OpenCode) to interact natively with major browsers (Chrome, Firefox, Edge) using the Model Context Protocol (MCP).
  * **Architecture & How it works:** Implements a multi-layered pipeline: the AI Agent communicates via **stdio** with an **MCP Server**, which tunnels commands through a local WebSocket **Daemon** directly to a **Browser Extension**. The extension translates requests into Chrome DevTools Protocol (CDP) commands. It features a built-in interactive REPL for manual debugging, structured JSON logging, and complex asset tracking via accessibility tree reference mapping.

* **[202FS Web](https://202fsweb.vercel.app/)** — *Cross-platform VPN Desktop/Mobile Client*
  * **Concept:** A high-performance, security-focused VPN client built for speed, complete privacy, and advanced user routing control across Windows, macOS, and Android.
  * **Architecture & How it works:** Developed on top of the **Tauri + Rust** stack for an ultra-lightweight desktop and system tray footprint. The UI is implemented as a fast web client powered by React/Next.js and styled with Tailwind CSS, deployed on Vercel's edge network. Features include a global hardware emergency network lock (**Kill Switch**), dedicated **Traffic Locking**, **DNS Guard** with protected resolvers, and per-app **Split Tunneling**. It also includes custom features like device fingerprint randomization (spoofing hardware specs) and a localized **VPN Hotspot** to share encrypted gateways with external devices like the Meta Quest 3.
